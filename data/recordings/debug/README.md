# Debug recordings

Files saved by the app's debug panel: press **D**, click **Record**, use the pen, then click **Stop and save**. Move the downloaded `debug-*.jsonl` file here.

Each file has the raw samples plus what the motion module made of them (`dx`, `dy`) and the settings in use. The format is in `docs/data-format.md` under "Debug recordings". **Load recording** replays them like any other recording.

Say what you did in the commit message or a note next to the file, like "slow circle, then the word hello, cursor drifts left".
